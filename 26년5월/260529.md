### TS 함수 매개변수 추론

- TS에서 함수 매개변수는 Any Type으로 추론된다.

  - CF) any Type이란?

    - TS에서 타입 검사를 받지 않는 특수한 타입

      ```
      let anyVar = 10;
      anyVar = "hello"; // 오류 발생 
      
      let anyVar :any = 10;
      anyVar = 'hello'; //  오류 발생 X 
      ```

  - ```
    function add(a , b){
    	return a+b;
    }
    //a와 b return 모두 any type으로 추론하는게 Default이다.
    
    function print(value){
    	console.log(value.toUpperCase());
    }
    // value가 문자열이면 상관없지만 숫자로 들어올 경우에 런타임 예외가 발생가능
    ```

    - any는 사실상 TS의 타입검사를 꺼버리는 수준

  - 클래스 상속시, extends하는 클래스에서 부모 클래스의 생성자를 'super' 키워드로 호출해야함

  - ```

    }

### 필드생략하기

- TS에서 생성자에 접근제어자를 사용할경우, 클래스의 필드선언이 불필요

- 생성자에 접근제어자를 사용했는데, 필드선언도 할 경우 중복선언이 됨

  - ```
    class Employee {
      // 필드
      private name: string;    // ❌
      protected age: number;   // ❌
      public position: string; // ❌
    
      // 생성자
      constructor(
        private name: string,
        protected age: number,
        public position: string
      ) {
        this.name = name;
        this.age = age;
        this.position = position;
      }
    
      // 메서드
      work() {
        console.log(`${this.name} 일함`);
      }
    }
    ```

  - 생성자에 접근제어자가 설정된 매개변수들은 this.필드 = 매개변수가 자동으로 수행이되므로 생성자 내부의 코드를 제거할 수 있음

  - ```
    class Employee {
      // 생성자
      constructor(
        private name: string,
        protected age: number,
        public position: string
      ) {}
    
      // 메서드
      work() {
        console.log(`${this.name} 일함`);
      }
    }
    ```
